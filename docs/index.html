🔍 FB Group Search

Quét bài viết Facebook Group, tìm khách hàng tiềm năng tự động

v1.0.0

🚀 Cách 1: Cài từ Edge Add-ons (khuyên dùng) 1-CLICK MIỄN PHÍ

Cài đặt 1 click, không cần Developer Mode, tự động cập nhật. Có sẵn trên mọi máy Windows 10/11.

🛒 Cài từ Edge Add-ons
⚡ Link Edge Add-ons sẽ có sau khi extension được duyệt (1-3 ngày). Trong lúc chờ, dùng Cách 2 bên dưới.

🛠 Cách 2: Cài thủ công (Chrome / Edge) MIỄN PHÍ

Dành cho người dùng Chrome, hoặc muốn cài ngay không cần chờ duyệt.

1
Tải file ZIP từ GitHub Releases → chọn file fb-group-search-vX.X.X.zip
2
Giải nén file ZIP ra 1 folder (click phải → Extract All)
3
Mở chrome://extensions (Chrome) hoặc edge://extensions (Edge)
4
Bật Developer mode (góc phải) → Click Load unpacked → Chọn folder vừa giải nén
5
✅ Xong! Vào Facebook Group bất kỳ → thấy nút 🔍 Quét Group góc phải dưới

📖 Cách sử dụng

1
Vào Facebook Group bất kỳ mà bạn là thành viên
2
Nhìn góc phải dưới màn hình → Click nút 🔍 màu xanh
3
Nhập từ khoá cần tìm (phân cách bằng dấu phẩy) → Click "🚀 Bắt đầu quét"
4
Xem kết quả → Click "📥 Tải Excel" để xuất file CSV

✨ Tính năng

  • Tự động scroll & quét tất cả bài viết trong group
  • Lọc bài theo từ khoá bạn nhập (hỗ trợ nhiều từ khoá)
  • Tự động trích xuất số điện thoại từ nội dung
  • Lấy link profile người đăng
  • Lấy link bài viết gốc
  • Xuất kết quả ra file Excel (.csv) — mở được bằng Excel, Google Sheets
  • Popup hiển thị ngay trên Facebook, không rời trang

❓ Câu hỏi thường gặp

Có bị Facebook khoá tài khoản không?
Không. Extension chỉ đọc dữ liệu hiển thị trên màn hình (DOM scraping), không can thiệp vào hệ thống Facebook.

Có cần đăng nhập không?
Có — bạn phải đăng nhập Facebook và là thành viên của group muốn quét.

Extension có an toàn không?
Có. Mã nguồn công khai trên GitHub, không gửi dữ liệu đi đâu, chỉ chạy trên máy bạn.
