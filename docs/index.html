🔍 FB Group Search

Quét bài viết Facebook Group, tìm khách hàng tiềm năng tự động

📥 Cài đặt (chỉ 1 lần)

1. Cài extension Tampermonkey trên Chrome/Edge

2. Mở link bên dưới → Tampermonkey sẽ tự hiện popup cài đặt

strongdinh.github.io/fb-group-search/fb-group-search.user.js
⚡ Cài đặt Script
⚠️ Yêu cầu: Cần cài extension Tampermonkey (Chrome/Edge/Firefox) trước khi click nút "Cài đặt Script".

📖 Cách sử dụng

1
Cài Tampermonkey + Script (chỉ 1 lần đầu)
Cài Tampermonkey từ Chrome Web Store, sau đó click nút "Cài đặt Script" ở trên
2
Mở Facebook Group bất kỳ mà bạn là thành viên
Bạn sẽ thấy nút "🔍 Quét Group" màu xanh ở góc phải bên dưới màn hình
3
Click nút "🔍 Quét Group" → Nhập từ khoá → Tool tự động quét & hiện kết quả!

✨ Tính năng

  • Tự động scroll & quét tất cả bài viết trong group
  • Lọc bài theo từ khoá bạn nhập (hỗ trợ nhiều từ khoá)
  • Tự động trích xuất số điện thoại từ nội dung
  • Lấy link profile người đăng
  • Lấy link bài viết gốc
  • Xuất kết quả ra file Excel (.csv)
  • Popup hiển thị ngay trên Facebook, không rời trang
